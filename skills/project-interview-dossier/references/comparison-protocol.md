# 维护验证：interview是否改善教材

这是维护实验，不是普通教材的额外必经流程。先按[正文规范](document-guide.md)完成直接生成版，再以相同项目、输入和生成版为基础进行interview修补。保持原始版本不可覆盖，不为比较重新随机生成另一套项目。

## 两个版本

直接生成版已经完成主作者通常会做的结构、语言、专业和数字自查，但尚未接收任何interview题目或审查反馈。冻结正文、输入、生成配置与Skill版本。盲问可并行，作者在冻结之前不读取题集。记录以输出为准，不能挑选多个初稿中最差或最好的一份。

同三位问者读取冻结版后按原协议作答，主作者回填真实缺口并复验，形成改进版。保存每次修改及其来源，不能把普通自查悄悄算成interview收益。如果没有必要修改，允许两版逐字节相同，不制造改动。

## 独立匿名比较

另启一位未参与作者或interview、且不继承其历史的代理。先仅给原始简历/实际JD、六板块教学标准和记录要求，让它确定代表性学习任务与迁移任务，冻结后才提供两份随机命名的甲乙文本。项目的作者设定、题集、答案、自评和版本来源均不提供。

比较者分别按各版阅读顺序理解并执行任务，不能把另一版的讲解作为本版前提。比较项目全貌、知识递进、操作可复做、判断与迁移、语言自然度、目录导航、事实与口径一致性，以及不必要负担。每项结论给原文位置和实际差异，允许持平、各有优劣或两版不合格。不以字数、题数、数据量、机器通过率或来源身份判优。

先保存质量结论，再揭示匿名映射和实际运行成本。记录实际耗时、调用次数与可得用量，未知不估造；区分interview新增成本与仅本次实验的比较成本。一次双文本阅读只能给材料层面的可学性证据，不声称已经做过真人学习实验。

## 默认策略结论

- 修复影响理解、操作或判断的关键缺口，且未造成明显结构/语言退化：保留必经。
- 收益只在局部或复杂/高风险工作明显，普遍成本不合适：改为按需，并写清触发条件。
- 没有实质提升，或使教材更散、更难学：取消默认强制，保留模块供明确调用和回滚。

比较者给出基于正文和成本的结论；主作者核对证据后如实同步主流程、协议、项目说明、安装版和ZIP，不能隐瞒不利结果。单案例是当前维护决策证据，不宣称全岗位通用效果已验证。两版均不合格则保存对照，另作最终修订和核查，不强选一版交付。

配套记录保留原始输入、两个版本、匿名映射、问题与账本、修改差异、质量判断、成本及策略结论。读者正文不添加实验标签、哈希和长表，不在两版中透露哪份经过审查。

## 当前维护结论

当前维持按需调用，触发规则统一见主Skill。一次已完成作者自查的Agent工程教材对照中，独立审查与作者补写后，评分过程、记忆压缩及去重边界有小幅局部改善；两版的整体业务理解与固定迁移任务基本成立，改进版评测段也增加了阅读负担。三镜头闭环投入较重，不能据此要求每份教材必经；同等作者追加投入的对照及更轻量审查效果尚未验证。启用后仍沿实测的三镜头闭环，不降低正文标准，也不外推为所有岗位已验证；新实验另存证据，不覆盖旧盲评。
