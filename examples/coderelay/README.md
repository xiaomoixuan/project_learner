# CodeRelay：从项目输入到学习手册

这是 [project-interview-dossier](../../skills/project-interview-dossier/SKILL.md) 的公开教学示例。它展示怎样把简历中的项目摘录和目标岗位职责，组织成一份让初学者从头认识项目、学懂核心能力并准备面试的手册。

## 从这里开始

1. 阅读[完整学习手册](handbook.md)：先看产品和一次完整使用，再学习架构、规划、工具、检索、记忆、个人开发与验证。
2. 需要了解生成依据时，查看[项目输入](project-input.md)与[目标岗位职责](target-role.md)。
3. 学完后查看[28 道实际 interview 问题与教材复答](interview.md)，检查能否用自己的话解释机制与取舍。
4. 查看[验证与前后对比](validation.md)，了解独立读者的实际判断、interview 的局部收益和限制。

## 这个示例包含什么

手册保留六板块，以研发人员使用 CodeRelay 分析 Issue、PR 与 CI、准备评论草稿为贯穿情境，同时介绍项目问答和组合任务。技术解释围绕功能如何完成展开，默认无需阅读代码、函数或接口字段。Agent 开发工程师的实际岗位要求决定了架构、规划、记忆和工程落地的讲解深度。

原始输入只提供项目概述，具体使用情境、业务对象、实现细节和开发过程采用统一的教学重构；原材料给出的实验结果与教学推演在手册中区分。本目录展示教材和审查结果，不是 CodeRelay 应用源码，也不验证全部教学设计都已真实实现。

## 使用这些输入试写一份手册

将本目录的项目输入和岗位职责交给已安装的 Skill，例如：

> 使用 $project-interview-dossier，根据 CodeRelay 项目输入与 Agent 开发工程师岗位职责，生成完整的项目学习手册。面向第一次接触该项目和相关机制的读者，先讲产品和一次完整使用，再解释核心工作、方案选择、难点、个人贡献与结果。已提供岗位职责，不再询问 JD。

公开输入只包含相关项目摘录和岗位职责；原验证使用的完整简历、私人材料和全部实验记录仍不公开。成品经过独立生成、局部整合、普通修订及 interview 回填，各阶段作用见验证页。
