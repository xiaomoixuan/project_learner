**CodeRelay · 研发协作多智能体平台**

个人项目 · 独立开发

技术栈：Python · FastAPI · LangGraph · PostgreSQL · Milvus · MCP · Next.js · SSE

面向代码、文档与研发任务信息分散的问题，独立实现项目问答、Issue/PR/CI 分析与多智能体任务执行平台。

- 工具体系：封装代码检索、知识问答、Issue、PR、CI 等 14 类工具，统一工具描述、参数校验与执行入口，通过 MCP 扩展调用能力，串联问题分析、证据检索与操作草稿生成。
- 任务编排：基于 LangGraph 将复杂请求拆解为具有依赖关系的子任务，支持最多 3 路并行执行；结合超时控制、失败反馈与有限重规划，约束重复调用和无边界执行。
- 检索与记忆：实现 Milvus 向量检索与 BM25 混合召回，结合会话记忆组织上下文；通过 Top-K 对照实验，将 9 条自建样例的业务硬规则通过数由 8/9 提升至 9/9，四项 RAGAS 指标均达到设定门槛。
- 执行治理：设计 ActionDraft 操作草稿与人工确认机制，分离模型建议和实际写操作；通过 SSE 展示工具调用、执行状态与证据来源，结合执行记录和审计日志支持失败定位与过程追溯。
